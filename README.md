# 机器学习课程作业 第一阶段

本仓库包含成员 A 第一阶段的数据清洗、历史探索分析、日频回测及买入持有/双均线基准。正式特征、机器学习模型和后续全流程总装尚待组员协作接入。

## 从哪里开始

- B 做特征先看 [清洗后的行情](outputs/tables/clean_prices.csv)，再看 [接口约定](接口约定.md)。
- 税费规则、字段和验证说明见 [税费更新说明](税费更新说明.md)。

## 目录

| 路径 | 内容 |
|---|---|
| data/ | 原始 TXT，保留原文件，用于重新生成清洗结果 |
| src/ | 数据读取、回测、基础分析代码 |
| outputs/ | 清洗后的行情、历史分析、基准结果和核查记录 |
| main.py | 第一阶段运行入口 |
| requirements.txt | Python 依赖及验证版本 |
|                  |                                            |

## 运行

建议 Python 3.11，在项目根目录执行：

```bash
python -m pip install -r requirements.txt
python main.py
```

原始数据文件保持不变；清洗输出截止 2026-10-23，历史 EDA 截止 2025-10-10。干净行情包含历史期和测试期，不能将整表全部用于训练。回测遵循收盘信号、下一交易日开盘成交，采用小组约定的股票税费（佣金万3最低5元、双向过户费十万分之一、卖出印花税万5），保留零滑点和可分割指数单位假设。

本阶段保留生成结果，便于组员直接读取和核对；临时缓存 work/ 与 __pycache__/ 由 .gitignore 排除。
税费测试：`python -m unittest discover -s tests -v`。仓位按扣费后资产计算；末日按市值估值，不强制卖出。
