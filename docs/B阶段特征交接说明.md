# B 阶段原始特征交接

行情来源为 A 的 `第一阶段.zip` 内 `outputs/tables/clean_prices.csv`。特征表保留从 2010-06-01 到 2026-10-23 的全部 3,980 个交易日。CSV 采用 UTF-8 BOM，首列为 `date`，后面是 17 列无量纲特征。收益率、波动率和比值均用小数表示。

## 接入 A 的项目

把 `src/features.py` 和 `outputs/tables/raw_features.csv` 放到 A 项目中的同名位置。A 可直接读取特征表，也可在现有 Python 环境中从项目根目录重新生成。

```powershell
python -m src.features
```

代码接口接收 A 清洗后的行情，要求使用升序、唯一的交易日期索引，以及 `open`、`high`、`low`、`close`、`volume`、`amount` 六列。

```python
from src.features import build_features

feature_df = build_features(prices)
```

`feature_df` 的 `date` 索引与行情逐行对齐。A 可按该索引贴标签，并检查标签所用的未来交易日是否跨越切分边界。相关性筛选和缩放参数留到确定训练子集后拟合。本批特征与预测周期和验证集边界无关。

## 字段与公式

`t` 指信号日，`O/H/L/C` 分别表示开、高、低、收盘价，`V/A` 表示成交量和成交额。所有窗口按交易日计数。表中的“近 N 日”含当天，“前 N 日”止于上一交易日。窗口长度按日线短周期及约一个交易月的观察尺度预设。

| 类别 | 字段 | 计算方式 |
| --- | --- | --- |
| 动量趋势 | `ret_1`、`ret_5`、`ret_20` | 当日收盘价除以 1、5、20 个交易日前的收盘价，再减 1 |
| 动量趋势 | `close_vs_sma_20` | 当日收盘价除以近 20 日收盘价均值，再减 1 |
| 震荡 | `rsi_sma_14` | 近 14 次收盘价变动的上涨点数之和，除以涨跌点数绝对值之和。窗口内价格无变动时取 0.5 |
| 震荡 | `stochastic_k_14` | 当日收盘价在近 14 日最低价至最高价区间中的相对位置。区间宽度为零时取 0.5 |
| 波动率 | `ret_vol_5`、`ret_vol_20` | 近 5、20 日 `ret_1` 的总体标准差 |
| 波动率 | `true_range_pct_mean_14` | 单日真实振幅为 `max(H, 昨收) − min(L, 昨收)`。每日用各自的昨收归一化，再取近 14 日均值 |
| 量价 | `volume_rel_20`、`amount_rel_20` | 当日成交量、成交额分别除以前 20 日对应均值，再减 1。分母为零时留空 |
| 量价 | `signed_volume_share_10` | 近 10 日按收盘涨跌方向赋予成交量正负号，平盘日赋零。带符号成交量之和除以同期总成交量，总量为零时留空 |
| K 线结构 | `gap_ret` | 当日开盘价除以上一交易日收盘价，再减 1 |
| K 线结构 | `intraday_ret` | 当日收盘价除以当日开盘价，再减 1 |
| K 线结构 | `range_vs_open` | `(H − L) / O` |
| K 线结构 | `upper_wick_share`、`lower_wick_share` | 上影线 `H − max(O, C)` 和下影线 `min(O, C) − L` 分别除以 `H − L`。当日振幅为零时两列均取 0 |

## 预热空值与核验

- 前 20 个交易日有部分列因历史窗口不足而留空，读入后为 `NaN`。本数据从 **2010-07-02** 起 17 列全部有效，共 3,960 行。使用全部特征贴标签时，可在日期对齐后剔除预热行。
- 已核对 CSV 回读、日期顺序和 A 的 `load_data` 接口。选取 6 个日期逐列独立复算公式，结果在浮点容差内一致。
- 已在 8 个截断点检查前缀一致性。把 2025-10-10 之后的价格、成交量和成交额分别改为原值的 7、3、5 倍，截止当日的特征保持逐值一致。另验证了输入单位变换不会改变这些特征。
