## 数据路径

`dataset/revised/` 是当前建模入口。C/D 使用其中 `train/`、`val/`、`processed/`、`test/` 和 `history/`。序列窗口止于信号当日。原 `dataset/train|val|test` 的测试答案及 metadata 仅用于评估。

`data/第二阶段_统一建模数据_修订版.zip` 保持原包 SHA256，供现有训练脚本直接读取。`dataset/revised/` 是其字节一致的解压副本，方便查看和其他模型接入。`data/clean_prices.csv` 与 `outputs/tables/clean_prices.csv` 相同，满足模型默认路径并保留 A 输出位置。

`dataset/revised/src/` 是数据包自带生成代码，作为独立包保留。仓库原 `src/features.py` 继续服务 A 流程，不把两个目录的模块混拷覆盖。

## 结果层级

`outputs/preds/` 是最终交付，四份 CSV 与最终运行 `handoff/` 原件一致。`outputs/metrics/` 是最终指标副本。逐日净值、逐笔交易及决策原因在最终运行的 `research_strategy_backtest/`。

| runs/ 下目录 | 用途 |
| --- | --- |
| `20261119_165036_ed592b` | 补入的本机原基准轮，第一轮搜索/验证的来源 |
| `20261119_201122_annualret_770f6c` | 第一轮候选、权重、预测和报告 |
| `20261119_231541_annualret2_5619ec` | 第二轮候选和当轮验证选中的配置 |
| `20261119_233827_annualret_final_cd62b2` | 最终推荐组合，本次交付使用它 |

第二轮验证优胜配置与最终推荐不同，按 `final_selection.json` 区分。第三轮只有脚本、报告和候选 CSV，原交付未含第三轮权重与完整运行。

原 JSON 中的绝对路径保留为历史来源信息，不能直接在新电脑使用。`reproduce_final.py` 仅用当前仓库路径及集成本地 `member_*`，支持移动仓库后运行。

## 交给 A / C / D

A 接收 `outputs/preds/` 的四份表与清单，按 date 合并。C/D 使用修订数据的统一日期和标签。模型的价格任务与交易任务独立，不能把价格目标 `pred_close_ret` 当下一开盘成交收益。分类概率需另行校准，不能直接当收益。

策略调用为 `CostAwareStrategy(config)(history, pred_trade_ret, account)`，返回 `[0,1]`，决策原因记录在 `.decisions`。收盘调用，次日开盘执行。复现本次成绩使用 B 的 `weighted_backtest`；A 原回测在保持当前权重时仍会重新平衡，语义不同，详见接口约定更新。
